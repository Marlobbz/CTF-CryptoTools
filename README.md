# CTF-CryptoTools
### 功能覆盖 - 37种 密码编码工具，覆盖 8大分类 - 所有工具支持 编码/解码双向操作 - 自动检测编码类型（基于正则匹配） - 高级选项面板（凯撒偏移量、栅栏行数等） - 历史记录（保存/恢复/清空） - 一键复制、下载为 .txt - 键盘快捷键： Ctrl+Enter 编码、 Ctrl+Shift+Enter 解码 ### 测试结果 - 9 个测试套件，570 个测试用例全部通过 - 覆盖率：正常场景 + 边界场景（空输入/特殊字符/中文）+ 错误场景 - 性能测试：100KB 输入全部在 100ms 内完成 - 集成测试：多层嵌套编码链路验证通过
